# Experiment 5: Exploring Descriptive Analytics Using the Iris Dataset

## Aim

To perform **descriptive analytics and exploratory data analysis** on the Iris dataset using Python and visualization libraries.

## Objective

The objective of this experiment is to understand the characteristics, distribution, and relationships among different features of the Iris dataset using statistical summaries and graphical visualizations.

## Dataset

The **Iris dataset** contains measurements of iris flowers belonging to three different species:

* Iris Setosa
* Iris Versicolor
* Iris Virginica

### Features

* Sepal Length
* Sepal Width
* Petal Length
* Petal Width
* Species

## Topics Covered

* Loading the Iris dataset
* Inspecting dataset structure
* Generating descriptive statistics
* Counting categorical values
* Univariate data analysis
* Feature distribution analysis
* Histogram visualization
* Boxplot visualization
* Pairplot visualization
* Comparing features across species

## Descriptive Analytics

### 1. Dataset Inspection

Basic information about the dataset is examined, including:

* Number of observations
* Number of features
* Data types
* Dataset structure

### 2. Summary Statistics

Descriptive statistics are calculated to understand the numerical features using:

* Mean
* Standard deviation
* Minimum
* Maximum
* Quartiles

### 3. Species Count

The number of observations belonging to each Iris species is analyzed to understand the distribution of categorical data.

## Data Visualization

### Histograms

Histograms are used to visualize the distribution of numerical features such as:

* Sepal Length
* Sepal Width
* Petal Length
* Petal Width

### Boxplot

A boxplot is used to compare **sepal length across different Iris species**.

It helps identify:

* Median values
* Data spread
* Quartiles
* Potential outliers

### Pairplot

A pairplot is used to visualize relationships between multiple numerical features and identify patterns among different Iris species.

## Tools and Technologies

* Python 3.x
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

## Learning Outcomes

After completing this experiment, the learner will be able to:

* Understand the structure of the Iris dataset.
* Calculate descriptive statistics.
* Analyze categorical and numerical variables.
* Examine feature distributions using histograms.
* Compare groups using boxplots.
* Identify relationships between multiple features.
* Use visualization techniques for exploratory data analysis.
* Interpret patterns and trends in a dataset.

## Result

Descriptive analytics was successfully performed on the **Iris dataset**. Statistical summaries, species counts, histograms, boxplots, and pairplots were used to explore the characteristics and relationships among the dataset features.

## Conclusion

This experiment demonstrates how descriptive analytics and visualization techniques can be used to understand a dataset before applying advanced analytical or machine learning methods. The Iris dataset provides a simple and effective example of **exploratory data analysis and feature relationship analysis**.
